## Problem

Today, Epic acceptance criteria are hand-written by the Manager (or operator) from scratch. This is slow and produces uneven AC quality across Epics — some have 3 ACs, some 13; some are measurable, some aspirational. AI-assisted AC suggestion could improve quality and consistency.

However, [Microsoft Research 2026 — Intent Formalization: A Grand Challenge](https://www.microsoft.com/en-us/research/publication/intent-formalization-a-grand-challenge-for-reliable-coding-in-the-age-of-ai-agents/) explicitly warns: *"Informal requirements must be validated by users. There is no oracle for spec correctness."* Naive AI-generated ACs without validation backstop would amplify rather than reduce drift.

This Epic adds AI-suggested ACs **with the reconciler from Epic #1271 child C3 (#1289) acting as the validation backstop**. The reconciler computes truth-status per AC; if AI-suggested ACs don't reconcile against measurable evidence sources, the suggestion is rejected.

## Goal

Manager writes problem statement; AI proposes 3–7 measurable ACs (free fleet/free-cloud lane, G3 zero-cost); Manager edits/approves; reconciler-backstop measurability check verifies each AC is computable from a known evidence source before it enters the Epic body.
