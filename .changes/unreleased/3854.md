### Phase-0 research: programmatic guardrails for local-worktree git protocols (#3854)

Delivered the git-protocol → guardrail-status map: most protocols are already enforced (canonical-main RO,
one-ticket-per-worktree, branch-naming, ticket-ref commits, merge-from-testing, push-gates), with four
genuine gaps — (A) raw `git worktree add` bypasses the fetch-first `agent-worktree.sh`; (B) worktree
freshness is declared-not-verified (`git-freshness-check` never fetches first); (C) governance measurements
read the stale local checkout not `origin/main`; (D) `install-hooks.sh` hardcodes a worktree abs-path into
the deployed pre-push hook. Each is mapped to its owning Agile role + a prevention-first (hook→validator→
test→CI), fail-closed guardrail reusing existing surfaces. Validated by a ≥90 cross-family council
(mistral 95 / meta 97 / gemma 98; Gwet 1.0).
