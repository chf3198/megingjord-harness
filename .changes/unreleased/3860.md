- **Hook-install path portability + dangling-path self-heal (#3860, Epic #3854 GAP-D):**
  `scripts/global/install-hooks.sh` now resolves `hooks_src` against the **canonical** checkout
  (`git rev-parse --git-common-dir` → main worktree) instead of `--show-toplevel` (the current
  worktree), so a symlinked/appended hook path never hardcodes a worktree that dangles when it is
  deleted (the #2508 "pre-push: <path>: not found" trap). Fail-open to the current root if the
  common-dir is unresolvable. `hook-symlink-health.js` gains `scanAppendedPaths()` (reads hook FILE
  content for embedded absolute `…/scripts/hooks/*.sh` invocations whose target is gone — invisible
  to the symlink classifier) and `healAppendedPath()` (repoints a dangling ref to the canonical
  script, **fail-closed** when no canonical target exists) with a schema-v3 G8 self-heal event.
