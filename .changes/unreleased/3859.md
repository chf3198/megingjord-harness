- **Measurement-base guard (#3859, Epic #3854 GAP-C):** governance measurement (governance-surface-census
  and audits) now resolves against `origin/main` via a shared fail-open shim
  `scripts/global/measurement-base.js` (`assertMeasuringOriginMain`, mirrors `loadLocalEnvOnce`). The
  census snapshot carries a `measurement_base` annotation (`behind` + staleness note) so a stale local
  canonical checkout can no longer masquerade as an `origin/main` measurement, and warns on stderr when
  stale. Graceful offline fallback (behind=null → measure local tree, G6); opt-out
  `MEGINGJORD_NO_MEASUREMENT_BASE_CHECK=1`. READ-ONLY — the only side effect is a fail-open `git fetch`.
  The same fetch-before-measure principle is wired into the readability diff gate
  (`lint-readability-core.js` resolveBaseRef) so a stale/shallow CI base can no longer sweep
  unrelated files' pre-existing warnings in as net-new.
